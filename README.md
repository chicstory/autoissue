# 🚗 ThePathLab Auto Issue (모빌리티 데일리 결함·신차 인텔리전스 허브)

10대 주요 자동차 제조사(현대·기아·제네시스, BMW·MINI, 벤츠, 폭스바겐·아우디, KGM, 쉐보레, 르노, 토요타, 포드, 테슬라 등)의 **국내 국토교통부 리콜 공고, 미국 NHTSA 해외 선제 결함 공고, 신차·페이스리프트 출시, OTA 무상수리 캠페인**을 매일 자동으로 수집하고 체계적으로 제공하는 ThePathLab 패밀리 서비스입니다.

---

## 🌟 주요 기능
1. **국내외 하이브리드 듀얼 트랙 수집**:
   - 국내 국토교통부 자동차리콜센터 최신 공고
   - 미국 도로교통안전국(NHTSA) 공식 결함 조사 및 해외 선제 리콜 (국내 도입 전 사전 대비)
   - 국내외 주요 자동차 매체 RSS 피드
2. **10대 제조사 그룹 & 카테고리 듀얼 필터링**:
   - 제조사별 칩 필터 (현대기아, BMW, 벤츠, 아우디, KGM, 쉐보레, 르노, 토요타, 포드, 테슬라)
   - 카테고리 알약 (🚨 리콜, 🚗 신차, 🔧 무상수리, ⚡ 전기차/배터리, 📰 업계 이슈)
   - 0초 실시간 통합 검색
3. **ThePathLab 엔진 백과(`engines`) 연동**:
   - 리콜 차종 태그 클릭 시 해당 파워트레인 실측 제원표로 원클릭 이동
4. **글로벌 다국어 지원**:
   - Google Translate 기반 KO | EN | RU | ES 실시간 번역
5. **1-Click 원스톱 데일리 발행**:
   - `run_autoissue.bat` 실행 시 [수집 ➡️ JSON 갱신 ➡️ 빌드 ➡️ GitHub 푸시] 자동 완료

## 📁 디렉터리 구조
```
autoissue/
├── index.html              # Dark Tech UI 기반 반응형 대시보드
├── auto_issue_collector.py # 국내외 리콜 & 뉴스 자동 수집 엔진
├── run_autoissue.bat       # 1-Click 자동 수집 및 배포 배치 스크립트
├── data/
│   ├── issues.json         # 정형화된 일일 자동차 이슈 데이터베이스
│   └── latest_stats.json   # 실시간 KPI 통계 요약 (리콜/신차/글로벌 건수)
└── README.md               # 서비스 가이드
```
